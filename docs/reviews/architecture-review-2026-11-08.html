Top recommendation

2 · Put the record tree behind one review-surface reader

The honesty lineage — ADR‑0053 → 0056 → 0059 → 0060 → 0061 — is this repo's spine, and it is currently enforced by convention: the classification record is read five ways with five corrupt-file policies, and eight of nine web surfaces hardcode the conformance field to unknown, a hazard the next surface slice will ship straight into. One shared read seam makes the honesty rule structural — missing · corrupt · tampered arrive named, tested once per record — and every future record the roadmap adds (P27's retry evidence, P54–P56) crosses it for free. Pair it with candidate 4's test adapter, which makes each new pin a short typed test instead of another 90-line world boot. Candidates 1 and 3 are the natural runners-up: both sit directly on freshly shipped, still-hot code (P53's live view, the batch protocol) and each pays for itself in weeks.

Findings gathered by two codebase walks over the 6-week churn hot spots; sizes and co-churn counts measured on the working tree (git log --since=2026-09-25; graft graph: 552 files, 13,903 symbols, 19,968 edges).
